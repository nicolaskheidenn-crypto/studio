# **App Name**: WebCraft Hub

## Core Features:

- Page Management: Allow administrators to create, edit, and delete content pages with a simple interface.
- Dynamic Content Display: Display managed text and image content on the website's frontend to visitors.
- Navigation System: Provide a responsive and intuitive menu system for users to easily navigate between pages.
- AI Content Draft Tool: Utilize AI as a tool to generate initial draft text for website sections, headlines, or article ideas based on user input.
- Contact Form: Implement a basic contact form allowing visitors to send messages or inquiries.
- Responsive Design: Ensure the website layout automatically adapts and is fully functional across desktop, tablet, and mobile devices.

## Style Guidelines:

- Color Palette based on Modernity and Clarity (Light Scheme): Primary color: A balanced, professional blue (#56ACDB). Background color: A very light, airy blue-grey for a clean base (#ECF4F7). Accent color: A subtle, complementary teal-green to highlight key actions and elements (#2E9474).
- Headline font: 'Space Grotesk' (sans-serif) for a modern and subtly tech-inspired feel. Body font: 'Inter' (sans-serif) for excellent readability and a clean, objective aesthetic.
- Use a consistent set of clean, line-based icons for clear visual communication without clutter.
- Adopt a minimalist, spacious layout with ample whitespace to ensure content remains the focus and enhance readability on all devices.
- Incorporate subtle, tasteful transitions and micro-interactions (e.g., hover effects, content loading) to improve user experience without being distracting.
